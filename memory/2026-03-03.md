### Bug Fixed: Gmail Draft Trigger
Major bug: when Will started typing an email in Gmail, the system was triggering inbox notifications as if a new email arrived. Cause: the Gmail trigger node had `"filters": {}` — completely empty — so it fired on every Gmail event including draft creation and autosave.

Fix applied: Added `INBOX` label filter to the Gmail trigger (`"filters": {"labelIds": ["INBOX"]}`). Drafts carry the `DRAFT` label, never `INBOX`, so they are now silently ignored. Applied via database edit (n8n stores workflows in sqlite, `workflow_entity` table) then n8n restart via LaunchAgent. Confirmed live.

Security note: Will explicitly asked which approach (UI vs database) fits the security goals. Zoé correctly recommended UI as the more auditable path. Will said he was comfortable with Zoé making the change directly — Zoé did so carefully with confirmation steps.

### Email Notification Enhancement Built
Problem set: notifications only showed a Gmail-generated snippet, no sender info, no way to read the full email, no action options.

Root cause of missing sender: Gmail trigger `simple=true` mode (default) returns metadata headers capitalized (`From`, `Subject`, `To`), but the n8n workflow expression was looking for lowercase (`from`, `subject`). No match, nothing displayed.

New architecture designed and built:
- Notification content: sender, subject, snippet (lean — no full body on every email)
- Inline buttons: **Read Full**, **Reply**, **Save for Later**, **Delete**
- **Read Full / Reply**: Zoé calls a new n8n "fetch-email" workflow with just the message ID → n8n fetches full body using `simple=false` → returns clean `{from, subject, text, html, date, replyTo}`. Gmail credential never leaves n8n.
- **Delete**: triggers existing `email-to-trash` n8n workflow
- **Save for Later**: logs to local `reading-list.md` file
- **Reply**: full body loads, Zoé drafts reply, goes through outbound queue → approval bot

New "fetch-email" n8n workflow created and verified live (webhook registered). URL saved as `N8N_WEBHOOK_FETCH_EMAIL` in `.env`.
