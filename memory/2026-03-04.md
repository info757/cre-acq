## CRE Acquisitions Intelligence Platform — BMAD Planning

### The Big Pivot
Started thinking about an OM Screener. Through conversation, realized it's actually
Stage 1 of a full acquisitions pipeline. Will's insight: "deals that pass screening
must be valued to make a LOI offer." That unlocked the full product vision.

### Full Pipeline
```
Stage 0 (future):  Crexi Scraper — surfaces deals matching rough criteria
Stage 1 (build first): OM Screener — reads OM, screens against buy criteria
Stage 2 (build second): Valuation Agent — DCF + direct cap → LOI offer price
Human: reviews verdict → signs LOI
```

### Why this is the right product
- Site search filters against broker metadata. OM Screener reads the actual document.
- Catches: pro-forma vs. trailing NOI gap, thin DSCR, lease roll concentration,
  expense ratio outliers, deferred maintenance signals — none of which site search catches.
- ARGUS costs $5-10k/year per license. Valuation Agent replaces it.
- Together: from discovery to LOI-ready offer, fully automated except human approval.
- Each stage is a LinkedIn demo. Full pipeline is the product reveal.

### Knowledge Architecture (3 layers)
- Layer 1: Public CRE underwriting fundamentals (no IP issues) — built in
- Layer 2: Configurable buy criteria per session (JSON, no code changes)
- Layer 3: Client historical deal data ingested per engagement (retainer story, post-MVP)

### One Repo Decision
Single repo: `cre-acquisitions-platform/`. Shared data model is the contract between stages.
Separate BMAD docs per stage for scope clarity, but same codebase and schema.
